2. Backup cluster  with cbbackupmgr 

Config:
/opt/couchbase/bin/cbbackupmgr config --archive /home/root/data/backup --repo myclusterbackup

Actual Backup:
/opt/couchbase/bin/cbbackupmgr backup \
--archive /home/root/data/backup \
--repo myclusterbackup \
--cluster couchbase://localhost \
-u admin -p 123456

View Backup:
/opt/couchbase/bin/cbbackupmgr info \
--archive /home/root/data/backup

Incremental backup: execute same command 

/opt/couchbase/bin/cbbackupmgr backup \
--archive /home/root/data/backup \
--repo myclusterbackup \
--cluster couchbase://localhost \
-u admin -p 123456

Compact and backup 

/opt/couchbase/bin/cbbackupmgr compact\
--archive /home/root/data/backup \
--repo myclusterbackup \
--backup 2024-10-15T05_50_08.2473937Z


Merge Backup: 
sample backups:
	2024-10-15T05_50_08.2473937Z

--disable-ft-indexes \
--disable-analaytics 

/opt/couchbase/bin/cbbackupmgr backup \
--archive /home/root/data/backup \
--repo studentBackup \
--cluster couchbase://localhost \
-u admin -p 123456
